ASSEMBLYAI DEEP DIVE
CORE SPEECH ENGINE

Supercharged by AssemblyAI Universal Speech API

How Monevo utilizes AssemblyAI's advanced speech understanding parameters to achieve near-flawless transcription on noisy real-world WhatsApp audio.

🔧 Production Configuration in src/services/assemblyai/
// AssemblyAI Universal Flagship Transcribe
await client.transcripts.transcribe({
  audio: audioBuffer,
  speech_models: ['universal-3-5-pro', 'universal-2'],
  boost_param: 'high',
  word_boost: [
    'Monevo', 'Naira', 'kobo', 'POS', 'light bill',
    'spending analytics', 'receipt', 'fuel'
  ],
  prompt: 'WhatsApp voice note with financial transactions in Nigerian English, Naira amounts, and receipt inquiries.',
  punctuate: true, format_text: true
});
🎯 Domain Word Boosting ('high')
Financial slang like "5k", "POS", and "kobo" are frequently misheard by vanilla speech engines. AssemblyAI's boost parameter forces high acoustic confidence for 40+ fintech terms.
🗣️ Contextual Prompt Engineering
By injecting specialized financial context into AssemblyAI's prompt parameter, the speech engine primes acoustic decoders for spoken transaction narratives, vendor names, and rapid price statements.
🛡️ Production Resiliency & Key Sanitization
Built-in MIME validation (OGG/Opus WhatsApp format), 25MB payload guardrails, and automated API-key redaction wrappers to safeguard secrets across error boundaries.
